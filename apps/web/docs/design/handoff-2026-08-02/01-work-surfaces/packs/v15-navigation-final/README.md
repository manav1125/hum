**Flat hierarchy — no indents.** Talk to Cue is the filled row; HQ and Work sit at the same level beneath it. The disclosure is a small `▾` on the **right edge after the count**, so nothing shifts horizontally when a section opens. **Canvas is 1a exactly** — mark, composer, four prompts, one sentence. The sentence now points **↑ at the rail** rather than opening a drawer, because the rail is where the answer already is.

## The expansion rule — why this doesn't become the wall
1. **Three items maximum, always.** Not "the first three that fit" — three, then "N more ›". A rail that grows with workload recreates the problem the calm page solved.
2. **HQ shows the three most urgent; Work shows the three with something live.** Different sorts, because the surfaces answer different questions.
3. **Only one expands at a time.** Opening Work closes HQ. Keeps rail height stable.
4. **Titles only — no buttons in the rail.** Deadline on the right, nothing else. Acting happens on the surface; the rail is a reminder, not a workspace.
5. **Collapsed by default on first run**, and it remembers.

## Skills added — the group is now closed at six
Passes the Tier 2 test cleanly: *"what can Cue do?"* is part of *"what is Cue?"*, and like Library it's a surface you'd **show someone** to explain the product.

| | |
|---|---|
| ◆ Agents | who works for you |
| ✦ Skills | what they can do |
| ↻ Rhythms | what runs without you |
| 🧠 Memory | what Cue knows |
| ▦ Library | what Cue has made |
| 👁 Watching | where it comes from |

Agents and Skills sit adjacent deliberately — an agent's capabilities *are* its skills, so the marketplace and the org chart belong together. **A seventh item must displace one of these, not extend the list.** That cap is what prevents thirteen happening again.
