# v23 — mobile complete (2026-08-03) · revises R1 from v22

## R1 revised: three tabs — HQ · ◉ · Work

**The argument that decided it:** with four slots the mark sits at position 2 of 4 — off-centre, which reads as an accident. **The raised centre button only works when it *is* the centre.** Three tabs restores the symmetry, and symmetry is what makes it look deliberate rather than arbitrary.

The tell was the owner's own instinct — *"if we kept four I'd prefer Library"*. **If the fourth slot is genuinely contested, neither candidate has earned it.**

### Where they went
- **▦ Library → Work's third view.** Desktop already does this (Things · Everything · Files). Library *is* work output, so it belongs inside the tab called Work rather than competing with it. No new destination, one segmented control.
- **👤 People → the ⓶ menu, plus every name in the app.** The honest reason: on a phone you almost never open People cold — you tap Rachel's name in a task, or you search. **Contextual entry is the real path;** the menu row is the fallback.

### What it costs, and the mitigation
People loses its glanceable prompt from the tab bar. **Mitigated: going-quiet people surface as HQ rows** — *"Sarah Chen is going quiet · asked twice, 11 days"*. That's strictly better than a tab badge, which can only ever say a number, never *who*.

## Contrast — eighth recurrence, and the class is now closed by rule
C5's "Send it" shipped at 3.76:1 (white on `#7F77DD`). Fixed to **`#534AB7`** — the review-violet *text variant* already defined in v9's A1 table, so no new colour enters the palette.

**The standing rule this settles:** a violet, amber, teal or blue **fill carrying white text is a text context**, so it takes the text variant — `#534AB7` · `#8A5A08` · `#0A6A6A` · `#2B53C4` — never the bright value. Bright values are for glyphs, borders, rings, progress strokes and ≥16px display type only.

Eight recurrences of the same shape means the remaining fix is structural, not vigilance: **name the tokens for their ground and role** — `--violet-fill` vs `--violet-on-fill` — so the wrong value can't be typed into the right slot.
