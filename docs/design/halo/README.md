## V2 — the visual layer (read this first)
Bee's lesson: the day opens as a **story** — prose headline, drawn journey, counts, chat, weekly patterns. That's the retention loop. V2 takes the bar and keeps our spine Bee lacks:
- **V1 · Day cover** — serif headline Cue wrote, journey arc with coarse place labels (HOME · VERVE · OFFICE — memory aid, not tracking; no street map), four tappable stat orbs, sync pill **on the cover**.
- **V2 · Ask your day** — every answer carries its moment (quote · speaker · time · tap to open); unfiled promises get "File it ›" inline — answers are doors into work.
- **V3 · This week** — rhythm bars + insights that are **counts with receipts** ("9 of 11 within a day"), each ending in a verb. No sentiment guesses.
- **V4 · Today tile** — Halo's live tile replaces the plain card while recording: aurora ground, breathing ring, today's counts, latest episode, thumb-reach ✓/✕ proposals on Today itself. H2's compact card remains the paused/idle/attention form.
- **Motion budget:** ≤3 live elements per screen, ≤3s loops, frozen under Reduced Motion.
- **One-line brief:** the Day must feel like a journal someone wrote about you — and every beautiful thing on it still passes the honesty rules. Beauty is the hook; the ✓ is the product.

## The organizing idea
Halo is **always a little behind the room, never in it** — so the lag number is worn proudly everywhere ("synced to 3 min ago" on the card, "3m behind" in the Island, "quiet since 4:10 · 3 min behind" on the Day). Nothing implies live listening; the first-capture waveform is labelled "what it recorded so far."

## H1 · Onboarding (7 steps, 3 drawn)
- **Step 2 · The promise** — three lines answering the three questions, before any permission. Phase-A cloud transit stated on this screen, plainly.
- **Step 4 · Pairing** — the single-bond warning inline; already-bonded recovery = red button + typed device name.
- **Step 5 · First capture** — teaches the only gesture (click = ⚑ bookmark, buzz = confirmation); Continue enables only when the transcript lands.
- Shape protected: **promise before permission, proof before autonomy.** Phase-A stubs: steps 1 (manual entry), 3 (SenseCraft hand-off), 4 (Seeed owns bond).

## H2 · The card
One component, two homes (ruling 1: **both**). Carries state + battery + **the sync line with exactly three shapes**: "up to date" · "synced to N min ago" · "N min behind · out of range — still recording." Pause = one tap, card goes slate while paused, resume is the same button. Live Activity reuses the run pattern; lock-screen copy is participle-only ("wearing"), never content. Island minimal = phase dot; the moving lag number is the liveness signal.

## H3 · The Day (ruling 2: **new surface**, reached from the card)
Episodes, not transcript. Empty hours compress to labelled dashed hairlines with reasons — the rail keeps the day's shape. **The ⚑ bookmark is the loudest element** (amber, "YOU MARKED THIS", your words verbatim) — nothing Cue inferred may outrank it. Proposals: ○ PROPOSED chip, ✓ files / ✕ dismisses (one gesture, undo, teaches). End-of-day quiet card: "on and 3 min behind — a calm day, not a broken one."

## H4 · Capture detail
Extractions above transcript ("what Cue took from it", each with state + destination). No transcript editor; unattributable crosstalk says so honestly. **Delete states the blast radius:** transcript + unaccepted proposals go; filed items stay unless removed too; audio is already discarded per retention — the sheet says so.

## H5 · The ten states
All drawn as card shapes, none toasts. Highlights: out-of-range is reassurance ("still recording"); sync-behind must visibly shrink; storage-full states the deletion rule (already-synced oldest first, unsynced untouched); bluetooth-denied is a full screen with the Settings route; a quiet day is green-labelled success.

## The five decisions
1. **Card: both** (one component, context prop).
2. **Day: new surface**, no fifth tab; feeds Today.
3. **Autonomy: parked-and-propose** default; "acts on the obvious" opt-in at step 6.
4. **Retention: transcribe-and-discard** default; keeping audio an explicit switch.
5. **Privacy: in-app always-visible recording state** (reserved red + the word "recording"); the device's own light is hardware's call, and the phone never claims more than the device delivers.

## Colour + invariants
Reserved red `#E5675B` = recording only · amber = bookmark + destructive warnings · never fake a number (lag real or absent) · nothing files without acceptance in proposes mode · ✕ teaches · push budget shared (Halo alerts replace, never double).
