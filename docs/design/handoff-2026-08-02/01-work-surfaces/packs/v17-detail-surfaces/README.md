# v17 — detail surfaces (2026-08-02)

Four surfaces named in the spec but never drawn at desktop size, all in the v15 shell.

## E1 · Thing detail (Renew Acme) — where the work actually happens
- **Left column = the work in state order:** needs you → Cue is doing (incl. queued) → made for this.
- **Right rail = context that doesn't change while you work:** who's on it (agents + receipts), who you're waiting on (with "Cue will chase Thursday"), people involved, and cost so far (done / spend / reversed).
- **The charter sits under the title, not in `⋯`** — editing it re-steers the agents, which makes it the most consequential control on the page.
- Ask-Cue scoped to this thing, bottom of the rail.

## E2 · Skills — never drawn before
- **Installed first, marketplace second** — what you have beats what you could have.
- Each row carries **run count and reversals**, the same receipts vocabulary as agents.
- Official / Community badges.
- **The rule that matters:** an update that widens permissions is never silent. *"v2.1 adds calendar write access"* renders amber with a **Review change** button — no auto-update.
- Footer promise: every skill declares what it can reach before install; changes need re-approval.

## E3 · Watching — never drawn before
- Every source states **what flowed through it today and how much became work** ("40 in — 31 filed, 9 dropped, 0 needed you"). That's the difference between a connections page and a watching page.
- **The no-op card:** *"Contact extraction ran 718× and found nothing — that's a bug, not a quiet week."*
- **"Connected but not watched"** — WhatsApp, Notion, Drive — the distinction the whole product turned on.
- **"What Cue skips"** — newsletters, receipts, 64 no-reply senders, with the rules inspectable.

## E4 · Work → Files
Grouped by thing, with the agent who made each file, so **provenance survives retrieval**. Includes the "Not in anything yet" group.
**Library is the gallery, Files is the list.** Use Library to see what Cue made; use Files to find one.
