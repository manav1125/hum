# One file from this pack is not in the repo

`cue-signon-prototype.html` is **deliberately absent**. It contains a real email
address in a filled-in form field, and this repo forbids personal data anywhere in
the tree — including the author's own, because examples get copied and real data
propagates through forks, screenshots and logs. See AGENTS.md, "Generic Examples".

`cue-signon-screens.html` (the static frames) **is** here and carries the same design.

To restore the prototype, replace the address with `user@example.com` and commit it;
the rule is about the data, not the file.
