# Cue HQ filing — batch add · provenance · dismiss (all surfaces)

One self-contained file: **cue-hq-filing.html**. Six frames: D1–D3 desktop (macOS app; web app is identical inside browser chrome) + 43–45 iPhone (same frames also live in Cue Mobile V3).

## Frames
- **D1 / 43 — Batch "Add tasks"**: multiline entry live-parses into rows. Per-row project assignment: confident → pre-filled chip "X ✓ (tap to change)"; ambiguous → open chip row + ＋ New project; no signal → italic "Leave unfiled — Cue will sort it" (default). Desktop is a two-pane ⌘⇧A modal; mobile a sheet. Footnote at entry: shield + "Added parked — nothing runs or spends until you say so."
- **D2 / 44 — Auto-file provenance**: ✨ pill inline on every auto-filed card ("✨ auto-filed → Seed raise · Move ›"). Move opens anchored popover (desktop, hover-revealed) / sheet (mobile): current pick marked, ＋ New project, closes with 🧠 "Moving teaches Cue — next one files itself." Below-confidence arrivals: amber "?" card, stays in triage, never guessed.
- **D3 / 45 — Dismiss vs done-elsewhere**: ✕ archives — never deletes, never completes. Row collapse + undo toast 5s (desktop: ink-dark centered pill, ⌘Z; mobile: glass pill above tab bar). Toast copy: "Archived — Cue learns from what you skip." Task sheet/popover order: ▶ Have Cue handle it · 📁 File to a project · ✓ Done elsewhere (green — completes for progress/ranking, ledger says "completed by you", never credits Cue) · ✕ Not relevant — archive. Desktop popover carries shortcuts ↵ / F / D / ⌫.

## Shared semantics (all three surfaces, non-negotiable)
1. ✕ = archive, reversible, feeds relevance learning. 2. "Done elsewhere" = completion without Cue credit. 3. Batch/manual arrivals land parked (can't auto-run or spend). 4. Auto-file requires confidence + always shows provenance; below threshold stays in triage.

Desktop chrome: Cue product system — Instrument Serif display, DM Mono microlabels, DM Sans body, ink #1A2230 on #F4F3EF, blue #3D6EE8. Mobile: V3 system (SF Pro, glass on aurora). Do not restyle either.
