FOUR LAYERS OF CONTROL

Built in, not bolted on.

✋
Named checkpoints

"Never send email without confirmation." "Anything customer-facing waits for me." Rules written in plain English, enforced on every agent, firing visibly when they catch something.

◼
Budgets that stop themselves

Every agent has a ceiling. When Ops hits its $2K cap it pauses itself and tells you why — raise it and continue, or leave it parked. Overruns are impossible by construction.

⚖
Policy-aware model routing

Route each task by cost, accuracy and policy. Pin a model to an agent, keep sensitive work on approved models, and see which model did what — no lock-in, ever.

☰
The act ledger

Every act every agent takes, timestamped and attributed — with live spend per agent, per mission, per model. Not a monthly invoice surprise: a running meter you can open any time.
